# Index of /home/books/

A minimalist book list styled like an old-school Apache directory listing.

## What it does

- Add books with a title, author, status, and short notes.
- Each book shows up as a fake "file" (e.g. `the-name-of-the-wind.want`) with a made-up last-modified date and size, just like a real Apache index.
- Click a filename to cycle its status: **want to read → reading → read**.
- Click any column header to sort.
- Click `rm` to delete an entry.
- Hebrew (and other non-Latin) titles and author names are fully supported and display right-to-left.

## Storage

Your list is saved in the browser's local storage — nothing is sent to a server. It will persist on this device/browser, but won't sync across devices.

## First run

The list ships with a few example entries marked "delete me." Remove them (if you not wish for them) with `rm` to start your own list.
